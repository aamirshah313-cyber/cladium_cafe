# Session handoff

Copy this structure into `PROJECT_STATE.md` at a phase boundary. Keep the resulting file below roughly 700 words.

```text
Updated:
Architecture/runbook version:
Active phase and step:
Goal of the step:

Completed this session:
-

Verification and evidence:
- command/test: result

Files changed:
-

Decisions made:
- D-___ (append durable rationale to DECISIONS.md)

Failed approaches / do not retry:
-

Uncommitted or external state:
-

Blockers:
-

Exact next action:
-
```

Never store secrets, credentials, customer PII, raw chat/audio transcripts, large logs, full menu data, or copied source documents in a handoff.
